# Python Data Cleaner

## About
A beginner-friendly Python project that cleans messy CSV files using Pandas.

## Features
- Detects and removes duplicate rows.
- Identifies missing values.
- Fills missing ages using the median.
- Replaces missing city values with "Unknown".
- Standardises date formats.
- Exports cleaned data into a new CSV file.

## Technologies Used
- Python
- Pandas

## How to Run
1. Install Pandas:
   `pip install pandas`
2. Place `messy_data.csv` in the project folder.
3. Run:
   `python cleaner.py`
4. Find your cleaned results in `cleaned_data.csv`.
